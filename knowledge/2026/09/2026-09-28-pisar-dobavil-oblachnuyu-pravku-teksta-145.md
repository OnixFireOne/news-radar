## Коротко
В Писаре для Windows и macOS появились облачная обработка диктовки и ИИ-команды для правки выделенного текста. Распознавание речи остаётся локальным, а в выбранный сервис отправляется только текст и только после включения функции.

## Контекст
Автор развивает приложение для диктовки Писарь. После выхода версии для Windows пользователь прислал пулреквест с обработкой распознанного текста через нейросеть; автор доработал его и добавил аналогичную возможность в версию для macOS.

## Главное
- Облачная обработка доступна в Писаре для Windows 1.0.5 и macOS 3.7.1; автор обозначает функцию как бета-версию.
- Поддерживаются сервисы DeepSeek, OpenRouter, OpenAI, Groq, Gemini, Claude и собственные серверы с OpenAI-совместимым API, например LM Studio, Ollama и llama.cpp.
- Приложение определяет сервис по ключу, проверяет ключ, загружает список моделей и предлагает подходящую модель.
- Распознавание речи выполняется на компьютере. В облако отправляется только текст; функция по умолчанию выключена.
- На Windows ключ хранится в зашифрованном виде, на macOS — в Связке ключей.
- Можно поручить нейросети обработать диктовку голосовой командой: например, «Писарь, исправь», «Писарь, сократи» или «Писарь, переведи на английский».
- Настройка «Править каждую диктовку» автоматически отправляет каждую продиктованную фразу на обработку без отдельной команды.
- В Windows добавлена правка выделенного текста: удерживая клавишу диктовки, можно попросить сократить текст, исправить ошибки или перевести его. Изменения можно отменить через Ctrl+Z.
- Правка выделения работает в большинстве приложений, где можно печатать, но не в терминале; её можно отключить в настройках.
- Для диктовки в Windows добавлена комбинация левый Ctrl + Win; настройки приложения переработаны и разделены на пункты «Диктовка», «Мозг» и «О программе».

## Как сделано
В настройках Писаря нужно выбрать облачный режим, указать сервис и вставить API-ключ. Приложение подбирает доступные модели; на Windows параметры находятся в разделе «Мозг», на macOS — в «Мозг Писаря». На Windows настройки сохраняются автоматически, на Mac нужно нажать «Сохранить».

После локального распознавания можно произнести команду для исправления, сокращения или перевода текста. Для выделенного фрагмента нужно удерживать клавишу диктовки и произнести указание. Если включить «Править каждую диктовку», обработка будет запускаться автоматически.

## Результаты
Функции вышли в версиях Windows 1.0.5 и macOS 3.7.1. По словам автора, приложение для Windows скачали более 300 раз после релиза. Автор также сообщает, что исправил первые ошибки по комментариям пользователей в день их появления; сравнительных измерений качества или скорости не приводит.

## Ограничения
Функция пока бета-версия. Для облачной обработки нужен ключ сервиса, а текст отправляется внешнему провайдеру или на настроенный сервер; обещание о локальной обработке относится только к распознаванию речи. Автор не приводит тестов качества, скорости, стоимости использования или сравнений моделей. На Windows редактирование выделения не работает в терминале. План офлайн-Мозга для Windows описан как будущая работа, а не доступная функция.

## Что взять себе
- Если важна конфиденциальность, учитывайте разницу между локальным распознаванием и облачной обработкой текста; облачную функцию можно не включать.
- OpenAI-совместимый API позволяет подключать как популярные облачные сервисы, так и собственный сервер.
- Голосовые команды и обработка выделения подходят для исправления, сокращения и перевода текста прямо в приложениях.
- Автоматическая правка каждой диктовки удобна, но отправляет текст на обработку без отдельной команды.
