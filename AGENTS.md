# AGENTS.md

Правила для ИИ-агентов (OpenAI Codex и другие) в этом репозитории.

Единый источник правил — **`CLAUDE.md`**. Прочитай его целиком до любой правки; всё, что там написано, обязательно и для тебя.
Затем — `specs/STATE.md` (текущее состояние и следующее действие).

Особенности запуска через Codex:
- Docker из песочницы Codex недоступен (нет доступа к `docker.sock`). Тесты и mypy не запускай — в отчёте перечисли, какие команды `docker compose run --rm --no-deps ...` нужно прогнать, их выполнит оркестратор.
- `.git` для тебя только на чтение: не коммить, не удаляй lock-файлы — напиши, какая git-команда нужна.
- `.env` не читать и секреты не печатать.
