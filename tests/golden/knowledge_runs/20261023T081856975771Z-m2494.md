# Message 2494

Источник: https://habr.com/ru/articles/1098004

## knowledge-v2:gpt-6-luna

## Коротко
Автор описывает AutoHarness — набор инструкций и скриптов, который заставляет CLI-агента изучать задачу, искать навыки и референсы, а затем проверять результат независимой критикой. По личным наблюдениям автора, Claude Code с ним работает предсказуемее, особенно в визуальных задачах, но формального бенчмарка пока нет.

## Контекст
Автор ранее работал в авиации и перенёс в работу с AI-агентами подход с предварительным изучением дисциплин и документации. Поводом стала задача нарисовать SVG-сцену из «Бегущего по лезвию 2049» без внешних генераторов: испробованные агенты действовали по памяти, не искали референсы и уверенно объявляли неудачный результат готовым. Из этой практической проблемы вырос AutoHarness.

## Главное
- Исходная проверочная задача — нарисовать SVG-сцену из Blade Runner 2049 с Райаном Гослингом и голограммой девушки в фиолетовом свете, не используя внешние SVG-генераторы.
- По наблюдениям автора, испытанные агенты не искали настоящий кадр, рисовали по памяти и могли испортить результат при последующих правках.
- AutoHarness сначала разбивает задачу на области знаний и ищет скиллы или MCP-серверы; источники ограничиваются теми, которым доверяет автор, например маркетплейсом Anthropic.
- Потенциальные скиллы проверяются на опасные действия, включая чтение ~/.ssh и команды вида curl | sh; сомнительные установки требуют разрешения пользователя.
- Для визуальной работы агент фиксирует параметры референса, а затем рендерит SVG в браузере, делает скриншот и сравнивает его с оригиналом.
- Критика отделена от создания: второй агент оценивает картинки вслепую, а одноразовый id защищает от подмены старым отзывом.
- Вердикт критика должен быть ровно одним из уровней blocker, major, minor или none; повторяющаяся три раунда проблема требует сменить подход.
- Скрипт autoharness проверяет журнал действий, а хук не позволяет Claude Code менять файлы до подготовки брифа.
- Автор заявляет совместимость с Claude Code, Codex CLI, Gemini CLI, Antigravity CLI, Qwen Code и GigaCode.
- Репозиторий проекта: https://github.com/D-Shey/autoharness.

## Как сделано
До начала работы агент делит задачу на области знаний и ищет для них готовые скиллы или MCP-серверы в источниках, которым доверяет автор, например в каталоге Anthropic. Кандидаты оцениваются по доверию, скачиваются во временную папку и проверяются на рискованные действия — например, чтение ~/.ssh или использование curl | sh. Ненадёжные варианты требуют подтверждения пользователя; если подходящего скилла нет, агент создаёт его сам. В конце задачи установленные материалы удаляются.

Затем агент получает референс и фиксирует измеримые ориентиры, пишет бриф с критериями качества, исходными ограничениями и способом проверки. В случае SVG агент открывает файл в браузере, делает скриншот и сопоставляет его с исходным кадром и замерами. Независимый агент-критик сравнивает результаты вслепую; отзыв привязан к одноразовому id, а оценка должна завершаться одним из вердиктов: blocker, major, minor или none. При серьёзной проблеме сначала уточняются правила и дополняется скилл, затем разрешается исправление; если проблема повторяется три раунда, подход нужно сменить.

AutoHarness сочетает инструкции для агента со скриптом autoharness, который проверяет журнал шагов и блокирует продолжение, если обязательные действия не выполнены. Бриф также подкреплён хуком, запрещающим Claude Code создавать или менять файлы до его подготовки. Скиллы можно проверять на тестовых задачах: два агента выполняют их со скиллом и без него, после чего судья сравнивает результаты вслепую. Для простых задач предусмотрен облегчённый режим без поиска и брифа.

## Результаты
Автор сообщает, что на его задачах Opus 5.5 с AutoHarness заметно лучше справлялся, чем без него, особенно с визуальными заданиями; выполнение стало, по его оценке, предсказуемее. Независимого количественного бенчмарка нет. В примере с исправлением безопасности отдельный критик обнаружил два способа обойти хук сразу и ещё три серьёзные проблемы позже, тогда как агент-автор исправлений пять раз назвал их minor.

## Ограничения
Оценка улучшения основана на личном опыте; честный бенчмарк не проведён, а полноценные запуски дороги и занимают время. Подготовка расходует дополнительные токены и время, поэтому автор предлагает облегчённый режим для мелких задач. Статья не приводит измеримых показателей качества, стоимости или скорости и не описывает результаты систематического сравнения разных CLI-агентов.

## Что взять себе
- Для сложных задач полезно заранее задавать критерии успеха, ограничения и проверяемые шаги, а не полагаться на общий промпт.
- Если результат можно сравнить с референсом, стоит зафиксировать ориентиры до начала работы и проверять итог независимым оценщиком.
- Самооценка агента ненадёжна: разделение ролей автора и критика может выявить проблемы, которые исполнитель пропускает.
- Такой процесс добавляет затраты времени и токенов; для простых исправлений уместен облегчённый режим.

## knowledge-v3:gpt-6-luna

## Коротко
AutoHarness заставляет CLI-агентов сначала изучить задачу и критерии, а затем проверять результат независимой критикой; это может помочь пользователям получать более предсказуемую работу, особенно в визуальных задачах.

## Термины
- SVG — формат изображений, описывающий рисунок с помощью кода.
- Хук — автоматическое правило, которое срабатывает при определённом действии и может его разрешить или запретить.
- MCP-сервер — подключаемый источник инструментов или данных для ИИ-агента.

## Контекст
Автор создал AutoHarness после того, как агенты не справились с просьбой нарисовать сцену из «Бегущего по лезвию 2049» в SVG: они не искали референс и уверенно заявляли о готовом результате. Автор связывает подход с опытом работы в авиации, где перед работой изучают документацию и правила.

## Главное
- Агент обязан сначала составить бриф: требования, условия пользователя и план проверки.
- Результат сравнивается с референсом; для этого код SVG сначала превращают в изображение.
- Работу проверяет отдельный агент, а скрипт следит, чтобы обязательные этапы не пропускались.
- Навыки проверяют на безопасность, а сгенерированные навыки можно тестировать сравнением работы с ними и без них.

## Как сделано
Перед выполнением агент делит задачу на области знаний, ищет подходящие навыки и референсы, затем составляет бриф с требованиями и способом проверки. Для SVG он открывает результат в браузере, делает скриншот и сравнивает его с кадром и предварительными замерами. Отдельный агент-критик оценивает работу. Скрипт autoharness ведёт журнал и блокирует переход дальше, если обязательные шаги не подтверждены. Подозрительные навыки проверяются перед установкой; автор сообщает о поддержке Claude Code, Codex CLI, Gemini CLI, Antigravity CLI, Qwen Code и GigaCode.

## Результаты
Автор сообщает, что Opus 5.5 с AutoHarness заметно лучше справлялся с его задачами, особенно визуальными, а результаты стали предсказуемее. Формального бенчмарка и количественных результатов нет.

## Ограничения
Эффект основан на опыте автора, а не на формальном бенчмарке. Подготовка требует времени и токенов, поэтому для простых задач предусмотрен облегчённый режим. Автор также отмечает, что написанные агентом навыки могут содержать ошибки и нуждаются в проверке.

## Что взять себе
- Для сложной задачи полезно заранее определить, что считать хорошим результатом и как его проверить.
- Не полагайтесь только на самооценку агента: независимая проверка может обнаружить пропущенные проблемы.
- Дополнительная проверка особенно оправдана для сложной работы; для мелких правок накладные расходы могут быть лишними.

## knowledge-v3:gpt-6.1-sol

## Коротко
AutoHarness добавляет к работе агента обязательную подготовку и независимую проверку. Это может помочь пользователям CLI-инструментов получать более предсказуемые результаты в сложных задачах, но преимущество пока не подтверждено формальным тестированием.

## Контекст
Автор раньше работал в авиации и хотел перенести привычку изучать документацию и заранее определять требования на работу с агентами. Отправной точкой стала задача нарисовать сцену из «Бегущего по лезвию 2049» кодом SVG: испробованные агенты не изучали настоящий кадр и плохо улучшали рисунок по замечаниям.

## Главное
- До выполнения задачи агент должен найти нужные знания, изучить референс и записать критерии хорошего результата.
- В Claude Code хук запрещает создавать и менять файлы, пока не готов бриф с требованиями и планом проверки.
- Результат оценивает отдельный агент, который не участвовал в работе; при сравнении изображений он не знает, какая версия новая.
- Скрипт autoharness проверяет записи о выполненных шагах, а не полагается только на соблюдение текстовых инструкций.
- Найденные скиллы проверяются перед установкой, а недостаточно доверенные требуют согласия пользователя.

## Как сделано
Агент разбивает задачу на области знаний, ищет или пишет скиллы, изучает референс и составляет бриф. Для SVG он открывает результат в браузере, делает скриншот и сравнивает его с исходным кадром. Независимый критик выдаёт оценку blocker, major, minor или none; программа проверяет одноразовый id отзыва и читает оценку напрямую. Перед исправлением серьёзной проблемы агент дополняет скилл правилами, а после трёх раундов с одной проблемой обязан сменить подход.

## Результаты
При исправлении безопасности AutoHarness основной агент пять раз подряд оценивал свою работу как minor. Независимый критик в первом раунде нашёл два обхода хука, затем ещё три серьёзные проблемы. Автор также сообщает о субъективном улучшении результатов Opus 5.5, особенно в визуальных задачах.

## Ограничения
Формального сравнения пока нет: полноценные испытания требуют денег и времени. Подготовка увеличивает расход времени и токенов. Написанные агентом скиллы тоже могут содержать ошибочные указания; для них предусмотрено сравнение выполнения тестовых задач со скиллом и без него.

## Что взять себе
- Для сложной задачи заранее задавайте проверяемые критерии и требуйте сверки с реальным образцом, а не с памятью модели.
- Поручайте итоговую проверку отдельному агенту: самооценка исполнителя может пропускать серьёзные ошибки.
- Для мелких правок используйте предусмотренный лёгкий режим без поиска и брифа, чтобы не тратить лишние ресурсы.
- AutoHarness можно попробовать с Claude Code, Codex CLI, Gemini CLI, Antigravity CLI, Qwen Code и GigaCode.
