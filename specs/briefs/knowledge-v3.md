## Зачем

Разбор «Шесть моделей, созданных с ML Intern» (neuronavt.blog, оригинал huggingface.co/blog/building-with-ml-intern)
точен по фактам, но человеку без ML непонятен: LoRA, дистилляция, GGUF, контрольная точка не объяснены; цифры
повторяются в «Главном» и «Результатах»; таблица расходов из оригинала потеряна; суть («модель, которой нет,
можно заказать агенту за $2–37») тонет в числах. Причина — `KNOWLEDGE_MD_PROMPT_FULL` (`knowledge-v2`): не сказано,
кто читатель; цифры требуются в двух полях; полей для терминов и таблицы нет.

Разбор — пересказ: дать понять, что в статье, чем она полезна, вытащить суть. Подробности — в оригинале или
в разговоре с ИИ.

## Что меняется в разборе

Имя `knowledge-v3` (`knowledge-v2` — уже текущий full-промпт). v2 остаётся нетронутым; выбор — ключом конфига.

| Поле | v2 | v3 |
|---|---|---|
| Читатель | не задан | пользуется ИИ-инструментами, но не специалист в теме статьи; простые слова, где можно |
| `tldr` (Коротко) | о чём и почему важно | суть одной мыслью + кому и чем полезно, без жаргона |
| `key_points` (Главное) | 5–10 пунктов с цифрами | 3–6 **идей**; число — только если меняет вывод |
| `results` | цифры | цифры, **без повтора** из «Главного» |
| `glossary` (новое) | — | до 5 терминов, которые читатель вероятно не знает: «LoRA — …», одна фраза; пусто, если таких нет |
| `table` (новое) | — | если в статье сравнение / список однотипного (проекты, модели, цены): строки `a \| b \| c`, первая — шапка, ≤ 9 строк; иначе пусто |
| `ask_ai` (новое, *см. открытый вопрос 2*) | — | 2–3 вопроса, которые стоит задать ассистенту, чтобы разобраться глубже |
| `read_original_if` | кому открывать | «подробности — в оригинале» + зачем открывать |

Порядок блоков: Коротко → **Термины** → Контекст → Главное → **Таблица** → Как сделано → Результаты →
Ограничения → Что взять себе → **Спросить у ИИ** → Читать оригинал, если…
Пустое поле — блок не выводится (как сейчас). Кривая таблица (разное число колонок, < 2 или > 5 колонок,
< 2 строк) — выкидывается с WARNING, разбор публикуется.

## Файлы

- `analyzer/prompts.py` — `KNOWLEDGE_FULL_V3_PROMPT_VERSION = "knowledge-v3"`, `KNOWLEDGE_MD_PROMPT_FULL_V3`.
  Правило про недоверенный текст в разделителях `<<<ARTICLE N>>>` — как в v2. Шаблоны и промпты
  `classic`/`spoiler` не трогать.
- `analyzer/json_schemas.py` — `KNOWLEDGE_FULL_SCHEMA_V3`: поля v2 + массивы строк `glossary`, `table`, `ask_ai`
  (в `required`, могут быть пустыми — строгий режим OpenAI требует все поля).
- `analyzer/knowledge_publisher.py` — промпт/схема по `knowledge.prompt_version`; рендер трёх новых блоков;
  проверка таблицы. Неизвестная версия → WARNING и v2.
- `config/config_watcher.py` (`DEFAULT_CONFIG`) **и** `config/settings.json` — `knowledge.prompt_version:
  "knowledge-v2"` в обоих. Переключение `settings.json` на v3 — после приёмки владельцем.
- `tests/test_knowledge_publisher_v3.py` (новый): без ключа — поведение v2 и прежний порядок заголовков;
  v3 — порядок блоков; кривая таблица выкидывается, разбор есть; пустые новые поля — без пустых блоков;
  промпт v3 содержит правило про недоверенные данные. Существующие тесты не менять.
- `tests/eval_knowledge_prompts.py` (новый, read-only БД, по образцу `tests/eval_digest_models.py`):
  `--message-id` (повторяемый), `--variants knowledge-v2:gpt-6-luna knowledge-v3:gpt-6-luna ...`; пишет JSON
  и md «до/после» в `tests/golden/knowledge_runs/`; автометрики: длина, **числа из разбора, которых нет
  в исходнике**, число терминов, есть ли таблица. Ничего не публикует.
- `mypy.ini` — новые файлы в `files=`, `--strict`.
- `docs/06_digest.md` — раздел про базу знаний: v3, новые блоки, ключ.

Новых зависимостей нет. Код пишет Codex по этому брифу; Claude Code проверяет диф, гоняет pytest/mypy в докере,
коммитит.

## Как проверяем до/после

1. 5 статей разных типов: ML Intern (кейс про ML — нужны термины и таблица), про Claude Code (своя тема —
   терминов ≈ 0), исследование, туториал, мнение. id подобрать по свежей базе.
2. Прогон v2 и v3 на gpt-6-luna (текущая модель `knowledge`); *см. открытый вопрос 3* — плюс v3 на gpt-6.1-sol.
   Цена: центы на luna, ~$0.1–0.2 с sol.
3. Владелец читает пары: понятна ли суть без оригинала, нет ли повторов, полезны ли таблица и термины.
   Автокритерии: v3 не длиннее v2 больше чем на 20%; выдуманных чисел нет; у статьи про Claude Code терминов
   ноль или почти ноль.
4. После переключения — проверить таблицу на живой странице neuronavt.blog (в т.ч. мобильная ширина): Astro
   рендерит GFM-таблицы, но стили темы не проверены.

Команды (после реализации):
