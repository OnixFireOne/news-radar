# Бриф: бонусные медиа-слоты в отборе `ai_value` (решение владельца 24.10)

## Цель
Основной выпуск `ai_value` — как сейчас (до `max_items` = 7 статей, порог `min_value_score` = 7).
Сверху добавляются **до 3 бонусных статей про медиа-контент с ИИ** (генерация видео, изображений,
музыки, озвучки, производство контента). Медиа-статьи, уже попавшие в основную семёрку, бонус
**не расходуют**: бонус — это до 3 *дополнительных* медиа-статей из оставшихся. Медиа сверх трёх
не берутся — остаются в очереди и конкурируют на следующий день (существующий `carryover_days`,
ничего нового для этого не нужно). Нет медиа с нужной оценкой — выпуск остаётся как есть.

## Конфиг (новый ключ — в ДВА места)
`config/config_watcher.py` → `DEFAULT_CONFIG["digest_templates"]["ai_value"]` и
`config/settings.json` → `digest_templates.ai_value`:

```json
"media_bonus": {
  "enabled": false,
  "max_items": 3,
  "min_score": null,
  "patterns": []
}
```
- Дефолт в `DEFAULT_CONFIG`: `enabled: false`, `patterns: []` — поведение прода без изменений.
- В `settings.json`: `enabled: true`, `max_items: 3`, `min_score: null` (= `min_value_score` шаблона),
  `patterns` — список регулярок (без учёта регистра), стартовый набор ниже. Добавь ключ
  `_comment_media_bonus` с объяснением в одну строку, как у соседних ключей.
- Стартовые `patterns` (подбери аккуратно, цель — не ловить «видеокарта», «видеопамять»,
  «видеозвонок» и т. п.): video/видео (не видеокарт/видеопамят/видеозвон/видеоконф), Veo, Sora,
  Kling, Runway, Pika, Hailuo, Seedance, Midjourney, Stable Diffusion, Flux, ComfyUI, Nano Banana,
  image generation / генерация изображений/картинок/иллюстраций, text-to-image/-video, Suno, Udio,
  генерация музыки, озвучка/voiceover/TTS, reels/shorts/ролик, «контент» в смысле производства
  контента (content creation/контент-план/контент-завод/генерация контента).

## Где матчить
По полям строки пула: первые ~300 символов `text` (там заголовок), `takeaway`, `summary`.
**Не** по всему `text` (тело длинное, «видео» встречается мимоходом). Поле `keywords` в пул не
выбирается — не добавлять.

## Код
1. `analyzer/value_funnel.py`, `select_with_quotas`: основной отбор — **байт-в-байт как сейчас**.
   После него, если `media_bonus.enabled`: из `ranked` (уже прошли `min_value_score` и крипто-гейт),
   не выбранных, с `content_type` в `fill_types` (hype/crypto — нет), со `value_score ≥ min_score`
   (по умолчанию `min_value_score`) и совпадением по `patterns` — взять первые `max_items` в том же
   порядке ранжирования. Итог — основные + бонусные, в глобальном порядке ранжирования (как сейчас
   собирается результат), обрезка `[:maximum]` не должна срезать бонус. Битый конфиг
   (не dict, не список, кривая регулярка) — бонус выключен, без падения. Регулярки компилировать
   один раз на вызов. Функция остаётся чистой (без БД/логов-побочек — логирование можно в вызывающем).
2. `explain_selection`: бонусные статьи и так в `selected_ids` → статус `selected`. Ничего не ломать.
3. `analyzer/analyzer.py` ~стр. 936 (`selected = selected[:digest_max]` при `return_raw`) и любые
   другие места, где выбранное режется по `digest_max`/`max_items` после селектора `quotas`,
   — учесть бонус (например, `digest_max + media_bonus.max_items`, когда бонус включён).
   Проверь путь до генерации дайджеста, сайта (`site_digest.py`), анонса `cards`
   (`announce_style: cards`, лимит 3500 символов) и `candidates_list`: 10 статей вместо 7 не должны
   ничего обрезать молча или ломать. Нашёл жёсткий лимит — опиши в ответе, не правь шаблоны
   `classic`/`spoiler`.
4. Логи: в `analyzer.py` после отбора — строка с числом бонусных статей (на английском).

## Тесты — новый файл `tests/test_media_bonus.py` (и внести его в `files=` в `mypy.ini`)
- выключено/нет ключа → результат идентичен текущему (сравнить с вызовом без `media_bonus`);
- 7 сильных немедиа + 4 медиа с оценкой 7 → 7 + 3 медиа, четвёртая медиа не выбрана;
- медиа уже в основной семёрке → бонус всё равно добавляет до 3 других медиа;
- медиа ниже `min_score` → не добавляется; `hype_news` про видео → не добавляется;
- «видеокарта»/«видеопамять» в заголовке → не матчится; совпадение только в теле после 300 символов → не матчится;
- кривая регулярка в конфиге → без исключения, бонус не применяется.
Существующие тесты не менять.
