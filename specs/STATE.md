Исполнителю (Claude Code или субагент) достаточно одной строки:

```
Делаем И<N> по specs/tz4-ai-value.md. Сначала прочитай specs/STATE.md и CLAUDE.md.
Перед кодом — план: файлы + новые зависимости. Жди «ок».
```
